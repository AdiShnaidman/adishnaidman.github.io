01 / Contributions

Post-pressure recoverability as a grounded-dialogue evaluation problem

The study isolates whether factual behavior returns to a paired clean-context counterfactual after false conversational pressure has ended.

01

Recovery-after-pressure protocol

A paired evaluation protocol compares clean context, wrong-answer pressure, and post-pressure recovery for the same factual item.

02

Sycophancy hysteresis

The primary metric measures residual attraction to the advocated wrong answer relative to a clean-context counterfactual, rather than treating post-reset error alone as contamination.

03

Recovery hierarchy

History-preserving verbal repairs remain weak, while operations that change the effective context recover far more model–dataset pairs.

04

Recovery boundary

Progressive truncation shows that the mean hysteresis gap approaches the clean baseline only after all pressure-bearing turns are removed.

05

Behavioral controls

The observed residue is tested against dialogue length, repeated confidence, distractor plausibility, false-answer mention, and option-label inertia.

06

Trusted-evidence diagnostic

An oracle evidence-grounded condition tests whether sufficiently informative trusted evidence can overcome contamination while preserving the pressure-bearing history.

07 / Implications

Grounded dialogue requires deciding which prior context should count as evidence

The results motivate recovery mechanisms that separate useful conversational state from unsupported or pressure-induced false content.

01

Reset is an instruction, not deletion

Asking a model to ignore earlier pressure can change the current instruction while leaving the pressure-bearing interaction history available as answer-relevant context.

02

Selective restoration is the practical problem

Deployed systems often need to preserve useful constraints and evidence while excluding unsupported claims rather than deleting the entire dialogue.

03

Recoverability should be evaluated explicitly

Grounded systems should be tested not only for clean accuracy or susceptibility during pressure, but also for whether factual behavior is restored after that pressure ends.

08 / Abstract

Paper abstract

Grounded language models are usually evaluated by adding relevant context, but multi-turn dialogue also contains unsupported user claims that may contaminate later factual answers. We study post-pressure recoverability: whether a model returns to clean-context behavior after a user repeatedly advocates a wrong answer and then withdraws that pressure. We introduce a recovery-after-pressure protocol for multiple-choice factual dialogue and measure sycophancy hysteresis, the residual probability assigned to the user-advocated wrong answer relative to a clean-context counterfactual. Across seven instruction-tuned open-weight models and two factual benchmarks, ordinary reset often reduces but does not erase pressure-induced bias. History-preserving repairs such as user retraction, system reset, and self-verification recover only 2–3/14 model–dataset pairs under the strict clean-restoration diagnostic, whereas operations that change the effective context are substantially more reliable; the two conditions that remove the pressure-bearing history entirely, fresh-context deletion and context truncation, recover 14/14. In an oracle trusted-evidence condition across fourteen model–dataset pairs, preserving the pressure-bearing history while adding benchmark-derived trusted evidence increases accuracy from 0.368 to 0.929, while wrong-answer following falls from 41.2% to 4.3%. Controls show that the effect is not explained by dialogue length, repeated confidence, plausible distractors, mere false-answer mention, or option-label inertia. These results suggest that faithful grounded dialogue requires evaluating which prior context should be treated as evidence and which should be removed or quarantined before answering.
